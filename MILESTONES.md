# Материалы проекта «Станция Ноль»

## Первый майлстоун — дизайн и питч

- `docs/milestone_1/GDD.md` — дизайн-документ;
- `docs/milestone_1/PITCH_SCRIPT.md` — речь примерно на полторы минуты;
- `docs/milestone_1/StationZero_Pitch.pptx` — презентация.

## Второй майлстоун — архитектурный проект

- `docs/milestone_2/ARCHITECTURE.md` — описание архитектуры;
- `docs/milestone_2/class_diagram.puml` — диаграмма классов;
- `docs/milestone_2/sequence_attack.puml` — диаграмма последовательности боя;
- `docs/milestone_2/activity_game_loop.puml` — диаграмма игрового цикла.

## Третий майлстоун — готовый проект

- исходный код находится в `src/`;
- игровые данные находятся в `assets/`;
- `docs/milestone_3/FINAL_SUBMISSION.md` — описание финальной версии;
- `docs/milestone_3/GITHUB_CHECKLIST.md` — список файлов перед сдачей;
- `docs/milestone_3/gameplay_demo.mp4` — короткая демонстрация;
- `tools/demo_input.txt` — команды для полного прохождения.
