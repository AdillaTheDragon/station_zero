# Проверка репозитория перед сдачей

- [ ] `StationZero.sln` открывается в Visual Studio.
- [ ] Проект собирается в `Debug x64`.
- [ ] Проект запускается через `Ctrl+F5`.
- [ ] Папка `assets/` присутствует в репозитории.
- [ ] В репозитории нет временных папок `.vs/`, `obj/` и `bin/`.
- [ ] В `docs/milestone_1/` лежат GDD, речь и презентация.
- [ ] В `docs/milestone_2/` лежат архитектурный документ и UML.
- [ ] В `docs/milestone_3/` лежат описание финальной версии и видео.
- [ ] Полное прохождение проверено.
