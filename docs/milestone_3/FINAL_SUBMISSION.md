# Финальная версия проекта

## Что реализовано

Финальная версия «Станции Ноль» содержит:

- консольный интерфейс;
- 15 комнат;
- перемещение по миру;
- предметы и инвентарь;
- 3 вида оружия;
- аптечки;
- 6 боевых встреч;
- закрытые проходы;
- запуск реактора и снятие блокировки;
- финального противника;
- победу и поражение;
- загрузку игровых данных из CSV;
- простую обработку неправильного пользовательского ввода.

Сохранения и загрузки игры намеренно не реализованы.

## Запуск

Открыть `StationZero.sln` в Visual Studio и нажать `Ctrl+F5`.

## Команды

Команды английские и всегда вводятся одним словом. Можно использовать полную или короткую форму:

```text
look / l
north / n
south / s
east / e
west / w
take_medkit / t_medkit
use_medkit / u_medkit
attack / a
inventory / i
map / m
help / h
quit / q
```

## Демонстрация

Для демонстрации удобно показать следующий фрагмент:

1. переход командой `north`;
2. бой командой `attack`;
3. подбор предмета командой вроде `take_fuse`;
4. использование предмета через `use_fuse`;
5. попытку неправильной команды, после которой игра продолжает работать.

Файл `tools/demo_input.txt` содержит полное прохождение.
