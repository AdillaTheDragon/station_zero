# Речь для презентации

«Станция Ноль» — небольшая текстовая ролевая игра, которую я делаю на C++ для Windows.

Игрок приходит в себя на заброшенной подземной станции и должен выбраться на поверхность. Для этого нужно перемещаться между комнатами, собирать предметы, сражаться с противниками и постепенно открывать закрытые участки станции.

Управление полностью текстовое. Команд специально немного, и все они английские: например, `north`, `look`, `attack`, `take_medkit` и `use_fuse`. Для основных команд есть сокращения: `n`, `l`, `a`, `t_medkit`. Каждая команда вводится одним словом, поэтому отдельный сложный текстовый парсер не нужен.

Боевая система тоже простая: игрок атакует текущим оружием, а если враг выжил, он наносит ответный урон. По ходу игры можно найти гаечный ключ, а затем электрошоковую дубинку, которые автоматически заменяют более слабое оружие.

Для прохождения нужно найти предохранитель и запустить реактор, получить карту доступа, найти служебный токен, снять блокировку станции и добраться до финального противника.

Все комнаты, предметы, враги и тексты хранятся во внешних CSV-файлах, а основная логика реализована на C++.
