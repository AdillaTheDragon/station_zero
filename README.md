# Станция Ноль

Учебная текстовая RPG на C++17 для Visual Studio. Игрок исследует заброшенную станцию, собирает предметы, сражается с врагами и пытается выбраться на поверхность.

Код специально сделан простым: нет отдельного парсера команд, отдельного загрузчика ресурсов и отдельной боевой системы. Почти вся логика находится в одном классе `Game`.

## Как запустить

1. Открыть `StationZero.sln` в Visual Studio.
2. Выбрать `Debug` и `x64`.
3. Нажать **Сборка → Собрать решение**.
4. Запустить через **Ctrl+F5**.

CMake не нужен.

## Команды

У каждой основной команды есть полная и короткая версия. Все команды английские и вводятся без пробелов.

```text
help / h
look / l
north / n
south / s
east / e
west / w
inventory / i
map / m
attack / a
take_<item> / t_<item>
use_<item> / u_<item>
quit / q
```

Например, эти команды делают одно и то же:

```text
north
n
```

Для предметов тоже есть короткая форма:

```text
take_medkit
t_medkit

use_medkit
u_medkit
```

В самой игре команда `help` или `h` показывает описание всех команд. Названия предметов для команд показываются рядом с предметами:

```text
- Аптечка [medkit]
```

Значит, взять её можно через `take_medkit` или `t_medkit`, а использовать через `use_medkit` или `u_medkit`.

## Карта

Команда `map` выводит простую ASCII-схему станции. Текущая комната отмечена символом `*`. Север находится сверху, юг снизу, запад слева, восток справа, и переходы в `rooms.csv` соответствуют этой схеме. Карта реализована обычной функцией `ShowMap()` без сложных алгоритмов.

## Защита от неправильного ввода

Игра не падает из-за обычных ошибок пользователя. Она проверяет:

- пустой Enter;
- пробелы внутри команды;
- неизвестные команды;
- `take_` и `use_` без названия предмета;
- попытку взять предмет, которого нет рядом;
- попытку использовать предмет, которого нет в инвентаре;
- попытку уйти во время боя;
- попытку пройти через закрытый проход;
- использование предмета не в той комнате;
- использование аптечки при полном здоровье.

`NORTH` и `north` работают одинаково.

## Что есть в игре

- 15 комнат;
- 6 противников;
- 3 вида оружия;
- аптечки;
- ключевые предметы;
- закрытые проходы;
- простой пошаговый бой;
- победа и поражение.

Сохранений нет.

## Исходный код

Теперь исходников всего три:

```text
src/
├── main.cpp
├── game.h
└── game.cpp
```

### main.cpp

Только запускает игру:

```cpp
Game game("assets");

game.Load();
game.Run();
```

### game.h

Содержит простые структуры `Item`, `Enemy`, `Room` и один класс `Game`.

### game.cpp

В нём находится почти вся логика игры:

- загрузка CSV;
- вывод комнат;
- `help`;
- проверка команд;
- перемещение;
- предметы;
- бой;
- победа.

Так сделано специально, чтобы код было легче читать и объяснять.

## Внешние данные

В папке `assets/` осталось только четыре файла:

```text
rooms.csv
items.csv
enemies.csv
ui.csv
```

CSV специально упрощены: ячейки разделяются символом `;`. Сложного CSV-парсера с кавычками нет.

## Стиль

Сохранились простые соглашения по именованию:

- `Game`, `ShowHelp`, `FindRoom` — классы и функции;
- `room_id`, `item_index` — локальные переменные;
- `room_id_`, `items_` — поля класса.

Архитектура намеренно минимальная: для проекта такого размера важнее, чтобы код было легко прочитать и объяснить.
